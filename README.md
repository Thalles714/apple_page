# Interface de produto — estudo de front-end

Recriação de uma interface inspirada na Apple para praticar HTML, CSS, JavaScript e manipulação do DOM. Não é um projeto contratado pela Apple e não possui vínculo oficial com a marca.

Projeto de estudo de Thalles Leal Tavares. [Portfólio atual](https://portifoliothallesleal.vercel.app/) · [Perfil profissional](https://github.com/Thalles714).

## O que este projeto demonstra

- Seleção de cor e tamanho.
- Troca de imagens do produto.
- Atualização do título a partir das opções escolhidas.

## Executar localmente

```sh
git clone https://github.com/Thalles714/apple_page.git
cd apple_page
python -m http.server 8000
```

Abra [localhost:8000](http://localhost:8000). Requer Python apenas para servir os arquivos; a interface usa HTML, CSS e JavaScript no navegador.

## Estrutura

- `index.html`: estrutura da interface.
- `style.css`: estilos.
- `script.js`: seleção de opções e atualização do DOM.
- `imagens/`: imagens utilizadas no exercício.
